# Hub website

The files in this folder, together with pages from `docs/`, make the hub
website. How it is built, checked and deployed is in
[site.md](../docs/development/site.md).

| File | What it is |
|---|---|
| `site.json` | The list of pages, each with its Markdown source. |
| `index.md` | The home page. |
| `404.md` | The page for an address that does not exist. |
| `template.html` | The HTML around every page. |
| `style.css` | The only style sheet. |
| `favicon.svg` | The icon in the browser tab. |

This README is not a page of the site.
