# Security policy

## Report a problem privately

Please do not report security problems in public issues, pull requests or
discussions.

1. Open the repository on GitHub.
2. Tap the **Security** tab. On a narrow screen, swipe the row of tabs
   sideways to find it.
3. Tap **Report a vulnerability**.
4. Fill in the form and submit it.

The direct link is
<https://github.com/shkriuss/shkriuss.app/security/advisories/new>.

Only the maintainer can see the report. You can talk about it there in
private until it is fixed.

## What to include

- The app, or the backend, and its version.
- The device and the Android or GrapheneOS build.
- What an attacker can do, and what they need first.
- Steps to reproduce it.

Please never include real user data, recovery keys, tokens or passwords.

## Supported versions

Only the newest release of each app gets security fixes. The
[apps page](docs/user/apps.md) shows the newest version of each app.

## Scope

What the project protects, and against whom, is described in the
[security documentation](docs/security/README.md).
