# Test pictures

Small pictures made by real encoders, for `../exif.test.ts`: each has the
camera date 2019-07-04 18:30:05 (DateTimeOriginal) and 2020-01-01 00:00:00
(DateTime) in its Exif.

- `libheif.heic`: made with libheif 1.23 (through pillow-heif), as HEIC
  tools write it.
- `pillow.png` and `pillow.webp`: made with Pillow.
