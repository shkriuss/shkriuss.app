# Apps

Every app of the suite, in the order of the roadmap, and how far each one
is. Every app has a package name of the form `app.shkriuss.<name>`, for
example `app.shkriuss.catalog`.

| App | What it is | Status |
|---|---|---|
| Catalog | A gallery of the shared design components and screens, for development. Most people do not need it. | Released: 0.3.0 |
| Water | Log the water you drink, see how close you are to your daily goal, and get reminders during the hours you choose. The pilot app. | Planned |
| Reminders | | Planned |
| Tasks | | Planned |
| Notes | | Planned |
| Sync | The only app with network access. It moves encrypted data only. | Planned |
| Budget | | Planned |
| Meals | | Planned |
| Repairs | | Planned |
| Shelf | | Planned |
| Trades | | Planned |
| Calendar | With Georgian public holidays and Orthodox feasts, computed on the phone. | Planned |
| Drive | An encrypted vault for files on the phone, with optional sync. | Planned |
| Photos | An encrypted vault for photos on the phone, with optional sync. | Planned |
| Grammar | Grammar checking on the phone, with the Harper engine. | Planned |

What the status means:

- **Planned**: not built yet.
- **In development**: being built. There is no release to install yet.
- **Released**: there is a release on GitHub. The status names the newest
  version. [Install it with Obtainium](install.md).

The full plan is in the [roadmap](../plan/PLAN.md#16-roadmap).
