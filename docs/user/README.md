# User guides

Guides for people who use the apps. Written for a phone screen first. The
hub website shows every page listed here
([site.md](../development/site.md)).

One guide per app:

- [Water](water.md): log the water you drink, see how close you are to
  your daily goal, and get reminders. Everything on Today, History and
  Settings, the five permissions, and the known problems of 1.0.2. On the
  hub website at `/water/`.
- [Reminders](reminders-app.md): set one-time and repeating reminders
  with a title, and see each one as a notification at its time.
  Everything on Upcoming, Past and Settings, the notifications, backup
  and restore, the five permissions, and the known problems of 1.0.0.
  On the hub website at `/reminders/`.

Pages:

- [Apps](apps.md): every app of the suite and how far each one is.
- [Install with Obtainium](install.md): how to install the apps and get
  updates.
- [Verify with AppVerifier](verify.md): how to check that an app is
  genuine, against the signing fingerprint.
- [Privacy](privacy.md): what each app stores, what leaves the phone,
  what the Sync app and its server will see, and that nothing tracks
  you. On the hub website at `/privacy/`.
- [Your recovery key](recovery-key.md): what the 24 words are, when an
  app asks for them, how to create them, enter them and see them again,
  how an app gets its keys from another app, the security screen, and
  what to do when setting up stopped or a key file is damaged. On the
  hub website at `/recovery-key/`.
- [The app lock](app-lock.md): what the app lock protects and what it
  does not, how to turn it on, when the app locks, notifications,
  screenshots, and what happens when the screen lock is removed. On the
  hub website at `/app-lock/`.
- [Back up and restore](backup.md): what a backup file is, how to make
  one and how to restore it. On the hub website at `/backup/`.
- [Reminders and notifications](reminders.md): for every app with
  reminders, when a reminder shows,
  how to allow notifications, and what happens after a restart of the
  phone before the first unlock, in Private Space and in another user
  profile. On the hub website at `/notifications/`.
