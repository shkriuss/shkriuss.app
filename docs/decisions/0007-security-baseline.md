# ADR 0007: Security baseline

- **Status:** Accepted, amended by [ADR 0010](0010-script-integrity.md), [ADR 0011](0011-worker-trusted-types-policy.md), [ADR 0014](0014-webassembly.md)
- **Date:** 2026-10-04

## Context

For a local-only web app, the [threat model](../threat-model.md) identifies script injection, the software supply chain and takeover of the developer's accounts as the main risks. As of 2026, the browser features that defend against script injection — Trusted Types and `Integrity-Policy` — ship in Chrome, Firefox and Safari.

## Decision

1. **Response headers.** Every app is served with the header set in [architecture §12](../architecture.md#12-security). The headers are generated by `@shkriuss/edge`, never written by hand, and staging adds `noindex`.
2. **Script integrity everywhere.** SRI on every script and module-preload tag, import-map `integrity` for lazily loaded modules, and `Integrity-Policy: blocked-destinations=(script)`. The Phase 0.3 spike verifies this works with our build. If any part cannot, the fallback is recorded in a new ADR. (Amended by [ADR 0010](0010-script-integrity.md): there are no module preloads; every chunk but the entry script loads with `import()`, checked through the import map.)
3. **Trusted Types with no policies** (`trusted-types 'none'`). Any exception needs an ADR. (Amended by [ADR 0011](0011-worker-trusted-types-policy.md): an app with worker scripts allows one policy, `shkriuss-workers`, for those scripts only; and by [ADR 0014](0014-webassembly.md): an app that declares WebAssembly gets `'wasm-unsafe-eval'` in its `script-src`.)
4. **No third-party resources at runtime**, of any kind.
5. **Permissions-Policy** denies every browser feature that Chromium ships, and leaves alone only these, which `UNDENIED_FEATURES` in `packages/edge/src/headers.ts` lists: `web-share`, because backups use the share sheet; `aria-notify` and `focus-without-user-activation`, which screen readers and keyboard users need; the Privacy Sandbox features (`attribution-reporting`, `browsing-topics`, `interest-cohort`, `join-ad-interest-group`, `private-aggregation`, `private-state-token-issuance`, `private-state-token-redemption`, `run-ad-auction`, `shared-storage`, `shared-storage-select-url`), which only matter to third-party content, of which the apps have none; and client hints (`ch-*`), which a browser sends only to an origin that asks for them. Apps opt in to anything else, such as the camera, in `app.config.ts`. (Reworded on 2026-10-10 to name the set as built; it said "denies every browser feature by default; `web-share` is allowed".)
6. **Code rules** are listed in `CLAUDE.md` and enforced by lint where possible.
7. **Supply chain:**
   - pnpm:
     - `minimumReleaseAge` of at least 3 days, with a documented override for urgent security fixes;
     - `trustPolicy: no-downgrade`;
     - install scripts blocked except for an allowlist;
     - a frozen lockfile in CI.
   - GitHub Actions:
     - pinned to commit SHAs;
     - `permissions: {}` by default;
     - workflows audited with zizmor.
   - CodeQL, dependency review, secret scanning with push protection, and Dependabot with a cooldown period.
8. **Accounts.**
   - Passkey or security-key two-factor authentication on GitHub, Cloudflare and the email account behind them.
   - Narrowly scoped API tokens, one per environment. (Cloudflare's Workers permission is account-wide, so one token per environment separates nothing while both environments share an account: [ADR 0020](0020-deployment-accounts.md), proposed, gives staging an account of its own.)
9. **DNS.** DNSSEC; CAA records; null MX, SPF and DMARC; no wildcard records.
10. **Transparency.** Build provenance attestations, and a published SHA-256 manifest of the files in each deployment.

## Consequences

- Some libraries cannot be used: those that need `eval`, inline styles, HTML injection or remote resources.
- Security is reviewed at the end of every phase, and whenever a change touches the network, permissions or dependencies.

## Alternatives considered

- **A nonce-based CSP generated by a Worker script:** unnecessary for static apps, and it adds server code.
- **A relaxed CSP** (`'unsafe-inline'`, `'unsafe-eval'`, third-party hosts): rejected.
