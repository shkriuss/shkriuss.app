# Apps

One folder per app, for the documents that belong to that app alone and
are written for development: its specification and the release checklist
of each version. Guides for people who use the apps are in
[user/](../user/README.md).

Folders:

- [catalog/](catalog/README.md): Catalog, the design gallery.
- [water/](water/README.md): Water, the pilot app, with its
  specification.

What else belongs here:

- A folder for each further app, with its specification (prompt 2.1 in
  [PROMPTS.md](../development/PROMPTS.md), with the app's name).
